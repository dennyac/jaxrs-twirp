# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability
reporting: open the repository's [Security tab][security] and choose
**Report a vulnerability**, or go to [the new advisory form][advisory].

Please don't open a public issue or pull request for a vulnerability. Include
the affected module and version, how to reproduce the problem, and its impact.

## Supported versions

Fixes are made on `main` and ship in the next release.
