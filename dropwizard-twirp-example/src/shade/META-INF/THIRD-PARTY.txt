Third-party material in the runnable example
==========================================

This index describes the resolved runtime inputs to this shaded binary jar.
It does not apply to the project's source or javadoc jars.

The original legal files from each dependency jar are preserved under:
  META-INF/third-party/<groupId path>/<artifactId>/<version>/<original entry>
The groupId path replaces dots with slashes. For example:
  META-INF/third-party/com/google/guava/guava/33.6.0-jre/META-INF/LICENSE

Dependency originals, including NOTICE.md and NOTICE.markdown, must be read
inside those dependency directories. META-INF/LICENSE and META-INF/NOTICE
at the shaded jar's top level are the project's own files, not merged
dependency notices.

Additional legal material is under META-INF/third-party/supplemental/.
PROVENANCE.txt there identifies the exact upstream versions and source files
used for the supplements. RUNTIME-SOURCES.tsv gives the coordinates, exact
source-archive URLs, and SHA-256 digests of the external runtime inputs.
The empty listenablefuture compatibility artifact contributes no classes.

  META-INF/third-party/org/glassfish/jersey/core/jersey-server/3.1.11/META-INF/
  Its Metrics-derived monitoring
  code and Jersey Bean Validation's Hibernate-derived classes have
  Apache-2.0 notices retained in apache-source-NOTICES.txt.

* Some upstream notices cover entire projects, including optional or test
  dependencies not present here. Those notices are preserved as written,
  not treated as the runtime inventory. In particular, Jersey Server's
  NOTICE.markdown mentions W3C documents, but its resolved binary contains
  no such document resources. The bundled Servlet version's terms are in
  its own 6.0.0 legal files, not the older Servlet terms mentioned in the
  project-wide Jetty notice. libffi build tools, tests, and documentation
  are not added as runtime dependencies.

EPL source availability
-----------------------

The source code for the EPL-covered components is available under EPL-2.0
from the exact source-archive URLs in RUNTIME-SOURCES.tsv. Full upstream
source distributions, including build files, are listed in
PROVENANCE.txt under "EPL source distributions". This jar aggregates the
dependency classes; it does not relicense those components as Apache-only.

The third-party programs are provided "as is", without warranties or
conditions of any kind. Their contributors disclaim liability for direct,
indirect, incidental, special, exemplary, or consequential damages.
The reproduced licenses contain the applicable terms and limitations.
